# (replace)

Responsive company portfolio website for the (replace) freelance team.

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Motion

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

The production output is generated in `dist` and can be deployed directly to Vercel.

## Customization

Company copy, the contact email, services, and team portfolio links are defined in `src/App.jsx`.
